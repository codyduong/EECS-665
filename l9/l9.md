1. Not all functions in C++ are made virtual because virtual functions incur
runtime overhead due to the vtable lookup,and only functions requiring
polymorphic behavior need to be virtual.

2. A vtable (virtual table) is a mechanism used by C++ to support dynamic
dispatch of virtual functions; it stores pointers to virtual functions of a
class and enables runtime resolution of calls to these functions.

3. Name mangling is a process by which the compiler encodes additional
information (like parameter types) into function names to enable function
overloading.

4. ```cpp
extern "C" void func() {} // Using extern "C" prevents name mangling
```

5. ```cpp
class MyClass {
void func() {} // Name mangling occurs for member functions
};
```

6. `_ZN7MyClass4funcEv`

7. `c++filt _ZN7MyClass4funcEv` -> `MyClass::func()`
