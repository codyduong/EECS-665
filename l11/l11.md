1. ```c
   #include <stdio.h>
   #include <string.h> 

   void vulnerable_function(const char *input) {
       char buffer[10];
       strcpy(buffer, input);
       printf("Buffer contents: %s\n", buffer);
   } 

   int main() {
       char input[50];
       printf("Enter your input: ");
       fgets(input, sizeof(input), stdin);
       vulnerable_function(input);
       return 0;
   }
   ```

2. Direct memory manipulation and lack of bounds checking allows buffer 
   overflows to occur. stdlib like `strcpy` does verify if target buffer is
   large enough. 

3. `-Wall -Wextra` compiler flags in `gcc` can identify these errors

4. `-fstack-protector` or `-fstack-protector-all` can prevent disallowed stack
   access. Alternatively any runtime check (ie. validate target size) and error
   or otherwise would also work.
